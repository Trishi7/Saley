## Phase A · skeleton (P0)
1. uv project, Python 3.12, src layout, pinned deps, ruff and pytest config in `pyproject.toml`.
2. `core/settings.py`: one field per env variable, `require(service)` per service, placeholders `<REQUIRED…>` count as missing.
3. `core/logging.py` (structlog, redaction of token/key/secret/password), `core/clock.py` (now_ist, today_ist, IST labels).
4. `core/egress.py`: allowlist, blocklist (linkedin.com and subdomains), per-host token bucket, timeout, tenacity retries,
   structlog per call, `egress_log` upsert, `EgressBlocked`. One `EgressTransport` for httpx (follows redirects hop by hop),
   a gspread `HTTPClient` subclass, and the same transport for the Anthropic client.
5. `core/llm.py`: Anthropic wrapper, `complete(model, system, data_blocks, schema)`, DATA blocks, cache `llm_cache`, cap `llm_calls`. No callers.
6. `core/db.py`, `core/models.py`: rw, ro, admin engines; session scope; typed models.
7. Alembic wired to settings (admin URL, else rw). 0001: users, llm_calls, llm_cache, job_runs, job_locks, egress_log, parity_checks.
8. `deploy/sql/roles.sql`: saley_admin, saley, saley_ro; default privileges; ro has SELECT only.
9. CLI (typer): web, bot, worker [--once JOB], news, sync --once, metrics --once, db-upgrade, health, discord send/read --test [--as].
10. Dockerfile (multi-stage uv), docker-compose.yml (postgres:16, web, bot, worker, news, caddy, egress stub), Caddyfile.
11. Bot: logs guild and test channel names, "pong" to "@Saley ping" in the test channel only.
12. Worker: APScheduler, registry, DB lock (15 min), job_runs rows, heartbeat. News: "news idle" every 10 min.
13. Tests on Postgres (`saley_test`), CI with a postgres service.

## Risks
- Token refresh for Google goes through google-auth's own transport. Host is allowlisted; noted in DECISIONS.
- discord.py gateway (websocket) cannot use the httpx transport. Scoped exception; REST calls from the CLI go through egress.
- First sync creates baseline touches for every filled step cell. Weekly metrics use the touch date, not the import time.
- Text dates `02.09.2026` are read as day.month (India) and flagged in data_quality.
- Goal ↔ person links come from an industry default map until the Goal column exists (D6). The UI says "by industry".
- job_runs grows ~1.7k rows a day; prune later (R2).
