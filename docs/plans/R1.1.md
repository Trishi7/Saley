## Design (accepted from the planner)
1. sync_id = `sheet_snapshot.id`. `run_sync` inserts a row inside the data transaction, only when the hash of the raw sheet values (plus tab status) changes. Requests read `max(id)` inside one REPEATABLE READ READ ONLY transaction; `?sync_id=` that is not current → 409 "Data changed. Reload the page.". job_runs stays the liveness signal.
2. `sheet_tab_status` (tab, status ok|stale, missing_headers, new_headers, last_good_sync_id, stale_since, reason, checked_at). A tab with a missing required header is skipped (no writes, no removals); `poc` needs `master`; a missing tab is stale; all required tabs stale fails the job. Known headers without a role are not "new".
3. Money blocked: deals = opportunity rows whose stage is not Won, Lost or Parked; a deal is blocked when one of its goals (industry rule) has a late blocking deliverable; one row per deal with its most-late deliverable (+N); unknown value = "no value on file"; total = sum of known values. View `v_money_blocked` (migration 0004).
4. `saley dev`: uvicorn in the main thread, BackgroundScheduler in the same process, first sync at once, `--port` default 8080; refuses its worker part when another worker ran in the last 2 × SHEET_SYNC_SECONDS (unless `--force`).
5. Browser QA: Playwright (dev dependency) driving installed Microsoft Edge; every non-localhost request is aborted and counted as a failure; no external link is clicked.
6. STE lint over a string catalogue: `static/words.js`, `web/words.py`, `bot/words.py`, plus `index.html` text nodes. ≤ 60 chars per string ({n} counts 4); no banned word.
7. `web/schemas.py`: one response model per endpoint, only shown fields; every response carries `sync_id`, `last_computed`, `stale`. Unknown query parameter → 422. limit + offset on every list. Cross-site requests → 403.
8. Fonts: system font stack; Google Fonts removed from the page and the CSP.
9. Drawer (D39): real email (known only) as mailto, LinkedIn and website as https links (new tab, noopener), else "none on file".

## Risks
- Partial sync hides stale data → red health line, PARTIAL job note, tile `source` says stale.
- Sheet verify races the team's edits → compare snapshot hash; wait for the next sync once.
- The QA browser could leave localhost → route abort + failure count.
- 50 parallel requests vs pool 10+10 → short transactions, pool_timeout, assert no 5xx.
