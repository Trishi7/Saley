- Any write to an Outreach PoCs row from the gate.

- LLM text on the page.
- A Vite dev server in the gate.
- A minimum Impeccable score. The human gave no number, so the score is recorded only.

## 3. Design

### 3.1 Stack and build (D144, D145)
- **App layout.** `web/` holds `package.json`, `package-lock.json`, `.nvmrc` (Node 24 LTS), `vite.config.ts`, `tsconfig.json` (strict), `eslint.config.js` and `index.html`. Code lives in `src/`:
  - `main.tsx`
  - `api.ts` (fetch with `X-Saley-Act: 1`, `sync_id`, the 409 banner)
  - `words.ts`
  - `views/*.tsx`
  - `components/ui/*` (shadcn, vendored)
  - `components/charts/*` (bklit, vendored)
  - `components/saley/*` (Legend, ComingSoon, Pager, ClickCard, StageBar, TouchTimeline, Funnel, Ring)
- **React.** React 19 with a hash router, so `/#today` and the other links stay as they are.
- **Tailwind.** Tailwind v4 with CSS-first tokens. Dark and light use a `class="dark"` toggle. The default follows the system. The choice is saved in localStorage (D163).
- **Fonts.** `@fontsource-variable` packages (one sans, one mono for tabular numbers). Vite bundles them into `assets/`. No Google Fonts and no CDN.
- **shadcn/ui.** Copied into the repo with the shadcn CLI once. After that it is plain source and needs no network at build. Components: card, badge, button, tabs, table, sheet, toast (Radix), pagination, tooltip, popover.
- **bklit.** Copied the same way into `components/charts/`. T10 checks its deps, its license, and that it inserts no runtime `<style>` and loads no remote URL. A chart that fails a check is replaced with the shadcn chart (Recharts) of the same shape.
- **Build output.** `vite build` has `base: "/static/app/"` and `outDir: ../src/saley/web/dist` (gitignored). It also writes `dist/build-stamp.json` (a sha256 of `web/src`, `index.html` and `package-lock.json`).
- **Serving.** FastAPI mounts `/static/app` → dist. `GET /` serves `dist/index.html` with a nonce. The URL contract in docs/08 Appendix A ("/static/{file}") does not change.
- **Docker.** A new first stage, `FROM node:24-bookworm-slim@sha256:<pin> AS web`, runs `npm ci --ignore-scripts` and `npm run build`. The run stage copies `dist/` into the package. The runtime has no Node. `.dockerignore` drops `web/node_modules`.
- **CI.** A node job runs `npm ci`, `npm run lint`, `tsc --noEmit` and `npm run build`. The python job uses the artifact.
- **Gate step 1.** It adds eslint, tsc and a build-stamp check: when the stamp differs from the sources, the gate fails with "Run npm --prefix web run build". `verify.py` `CODE_SUFFIXES` adds `.ts`, `.tsx` and `.json`.
- **Dev loop.** `npm --prefix web run build -- --watch` with `uv run saley dev`. There is no Vite dev server, so the CSP and the Host-port check (M7) stay as in production.

### 3.2 CSP (D146)
- `script-src 'self'` stays. There is no inline script, no `unsafe-inline` and no `unsafe-eval`. Vite emits external module scripts only. A test fails on any `<script>` without `src` in the built index.
- `style-src 'self' 'nonce-<per request>'`. Radix sheet and dialog use react-remove-scroll, which inserts a `<style>` element. A strict `'self'` blocks that element and logs a console error, and the brief needs zero console errors.
  - `GET /` puts a fresh `secrets.token_urlsafe(16)` into `<meta name="csp-nonce">` and into the header.
  - `main.tsx` calls `setNonce()` from `get-nonce` before the first render.
  - React `style={}` props use CSSOM. The CSP does not block them.
- All other pages (`/signin`, errors) keep the R4 `CSP` constant. `guards.py` gains `csp_with_style_nonce(nonce)`.
- `browser csp_clean` listens for `securitypolicyviolation` on every view, in both themes. It also counts console errors. The pass is zero for both.

### 3.3 Words and the STE lint
- `web/src/words.ts` uses the exact `key: "text",` form: `export const W = { tasksTitle: "Your tasks today", ... } as const;`. `ste_lint.JS_STRING` already matches it. `collect()` reads `web/src/words.ts` and `web/index.html`. It keeps `static/words.js` until the cut-over (T16).
- ESLint `react/jsx-no-literals` (`noStrings`, `noAttributeStrings`; allowed: `· — : / % +`) makes TSX take every visible string from `W`. `aria-label`, `title` and `placeholder` go through `W` as well.
- `words.py` stays the source of API text.
- A pytest checks that every `W.x` used in TSX exists, and that no key is unused.

### 3.4 Selector contract and gate scripts

  - `#tasks li.task` and `.drawer.on`
  - `[data-act=…]` on every state-changing control
  - `#toast` and the search ids
- New hooks: `[data-legend]`, `[data-tag]`, `[data-soon="<feature>"]`, `[data-feature]`, `[data-pager]`, `[data-kind]` on Needs a look cards.
- `scripts/browser_qa.py` (1110 lines, R4 MEDIUM) is split into `scripts/qa_browser/` (`core.py`, `checks_r1_r4.py`, `checks_r5.py`). The CLI stays.

### 3.5 Migration strategy (D147): strangler, one cut-over
- **During T10–T15.** `/` keeps the legacy static app. The new app is at `/next`: session needed, every mode, the same CSP with the nonce. Each page ticket ports one group of views to `/next` and runs its own browser checks on `/next` with `--base /next`, at 1440, one width. pytest and ruff stay green after every ticket, because the legacy app and its tests do not change.
- **At T16 (cut-over).** `/` serves the new app. `/next` and `static/*.js|css|html` are deleted. `ste_lint` drops `words.js`. browser_qa checks run on `/`.
- **Why not page by page inside one shell.** Two shells on one page would mean two routers and two toasts, and the CSP would differ during the move.
- **Why not big bang.** A big bang gives no checkable step for 6 tickets.

**Done value (D153).**

  - first_contact: the column's true form (TRUE / Yes / Y).
  - first_contact_type: the LI form the column uses (LI / LinkedIn).
  - Dates: today, written in the date format most cells of that column use.

**News (D150, D151).**

## 8. Risks
- **RAM on this laptop.** Vite + tsc (~1 GB), pytest and Edge per width compete for memory. Mitigation: D142 order, `--low-memory`, a build only when the stamp is stale, and no `--watch` during tests.
- **CSP.** A vendored component may insert styles or use eval. Mitigation: the nonce, `csp_clean` on every view in both themes, and component swaps (D148).
- **STE lint gaps in TSX.** Mitigation: ESLint no-literals, a words.ts usage test, and gate step 3 on words.ts and index.html.
- **Parity.** The new funnel and tiles must equal the sheet recount. 20 random Done/Undo can hit the Sheets API rate limit. Mitigation: a fixed seed, paced pushes, a reread before compare, and tear-down on failure.
- **Build reproducibility.** Mitigation: `package-lock.json`, `npm ci --ignore-scripts`, a digest-pinned node image, the build stamp, and CI building from the lock. Risk: esbuild or Tailwind oxide native binaries with ignore-scripts. Check them in T10. Allow only a named `npm rebuild <pkg>`.
- **Supply chain.** npm packages and the Impeccable installer. Mitigation: pinned versions, the security-reviewer reads the lockfile diff and the `.claude/` files, and `npm audit` in CI (report only).
- **Selector drift breaks R1.1–R4 browser rows.** Mitigation: Appendix B contract, the strangler, and a full `/verify` from step 1 after the cut-over. Never edit a matrix row to pass (docs/16).
- **Value vocabulary.** An empty column refuses Done (409). Mitigation: a clear message, and the SALEY_TEST seed holds vocabulary rows.
- **Seen semantics change.** Mitigation: the bot keeps the CLAUDE.md footer, and docs/08 is amended (D157).
- **The news start in dev may run while the human's `saley news` also runs.** Mitigation: the same lock, `SKIP LOCKED`, and the 6 h freshness rule.
- **`app.py` (783 lines) and `signals.py` (739) grow.** Mitigation: new routers `web/admin.py` and `web/today.py`, and `sales/vocab.py`.
